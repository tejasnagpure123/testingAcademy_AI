Advanced RAG Architecture

A deep dive into Hybrid Search, Query Rewriting, and Re-ranking for 5,000 VWO Test Cases

What is this?

This application is an end-to-end teaching demo showcasing how to upgrade a Basic RAG application to handle large-scale corpora (5,000 software test cases). By combining dense embeddings, sparse lexical weights, cross-encoder re-ranking, and dynamic query rewriting, we drastically improve context retrieval precision.

System Pipeline

Key Components

1 Hybrid Retrieval

Instead of relying solely on dense semantic embeddings (which might miss exact keyword matches), we use BAAI/bge-m3 to generate both dense vectors and sparse lexical weights simultaneously. Qdrant stores and searches across both dimensions natively.

2 Query Rewriting

Users often ask vague questions. We pass the user's query through a fast LLM (via Groq) to generate 3 alternative phrasings. This expands the search surface area, capturing documents that use different synonyms.

3 Cross-Encoder Re-ranking

Hybrid search returns a broad set of candidates. We use BAAI/bge-reranker-v2-m3, a cross-encoder model, to evaluate the pair of `(User Query, Document Chunk)` together. This accurately scores relevance before sending the context to the expensive Generation LLM.

4 Generation

The top 4 perfectly re-ranked chunks are passed as context to DeepSeek v4 Pro via OpenRouter. The model uses this context to accurately answer questions or generate new, consistent test cases matching the requested JIRA ticket.
