# Chapter 11 — Python Learning

This chapter focuses on fundamental Python concepts, progressing from basic syntax to more advanced topics like functions, decorators, data structures, and functional programming constructs (map, filter).

## Content Overview:

*   **`ex_01_Python_Basics/`**: Introduces Python's core syntax, variables, and basic I/O operations.
*   **`ex_02_Keyword_Identifiers_Variables/`**: Dives into Python's reserved keywords, rules for identifiers, and different types of variables.
*   **`ex_03_Literals/`**: Explains various literal types (numeric, string, boolean, collection) and their usage.
*   **`ex_04_Operator/`**: Covers arithmetic, comparison, assignment, logical, bitwise, identity, and membership operators.
*   **`ex_05_Condition_Loops/`**: Introduces conditional statements (`if`, `elif`, `else`) and basic loop structures (`for`, `while`).
*   **`ex_06_Switch_match/`**: Explores the `match` statement (structural pattern matching) introduced in Python 3.10.
*   **`ex_07_Loops/`**: Provides more advanced examples and exercises on loops, including nested loops and loop control statements (`break`, `continue`, `pass`).
*   **`ex_08_Funtions/`**: Covers function definition, parameters, arguments, return values, and different types of function arguments.
*   **`ex_09_Funtions_Scope/`**: Explains variable scope (local, enclosed, global, built-in) and the LEGB rule.
*   **`ex_10_Decorator/`**: Introduces decorators, their syntax, and how to create and use them for enhancing function behavior.
*   **`ex_11_Type_Conversion/`**: Demonstrates implicit and explicit type conversion functions.
*   **`ex_12_Lambda_Expression/`**: Explains anonymous functions (lambda expressions) and their use cases.
*   **`ex_13_List/`**: Covers Python lists, their methods, and common operations.
*   **`ex_14_Tuple/`**: Introduces tuples, their immutability, and typical use cases.
*   **`ex_15_Set_Dict_Map/`**: Explores sets (unordered collections of unique elements) and dictionaries/maps (key-value pairs) and their operations.
*   **`ex_16_Map_Filter/`**: Focuses on the `map()` and `filter()` functions for functional-style programming with iterables.
*   **`ex_17_Dict/`**: Provides further examples and exercises on dictionaries, including advanced operations.
*   **`ex_20_Collections/`**: Practices collections and file I/O through hands-on labs using text, CSV, and environment data.
*   **`ex_21_Pytest/`**: Introduces pytest test discovery, assertions, markers, fixtures, parametrization, and CSV-driven test data.

## Running the Pytest Examples

From the repository root, run the examples with the project virtual environment:

```powershell
.\.venv\Scripts\python.exe -m pytest Chapter011Python_Learning\ex_21_Pytest\Lab_181_pytest.py
```

See [`ex_21_Pytest/PyTest_Cheatsheet.md`](ex_21_Pytest/PyTest_Cheatsheet.md) for test naming rules, fixtures, markers, parametrization, and common pytest commands.
